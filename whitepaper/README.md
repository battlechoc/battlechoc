# battlechoc whitepaper

- [`whitepaper.md`](whitepaper.md): the whitepaper (draft for review).
- [`simulator/`](simulator): the agent-based economy simulator behind its numbers, with tests.
- [`figures/`](figures): all figures. Most are generated by the simulator; `crafting-loop.svg`, `season-lifecycle.svg` and `architecture.svg` are drawn by hand.

Regenerate every generated figure and `simulator/results.md`:

```
npm run whitepaper:simulate
```

Run the simulator's tests:

```
npm run test:whitepaper
```

The figures are plain SVG files (some animated), so GitHub and every browser show them without any build step. Animations stop for viewers who prefer reduced motion.
