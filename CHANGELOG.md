# Changelog

## [4.0.0](https://github.com/battlechoc/battlechoc/compare/v3.0.0...v4.0.0) (2026-10-27)


### ⚠ BREAKING CHANGES

* **shared:** cream covers a centred 3×3 area instead of a 2×2 anchored top-left at the tapped cell.
* **api:** the lab: discover recipes, craft items, equip them; levels refunded
* **shared:** equipment replaces building levels in the engine
* **pwa:** one Start button with matchmaking, the server AI and an offline fallback
* **api:** xp for offline records, Choclab paid in ingredients, highscore by rating
* **shared:** the turn-based exports of the shared package are gone.
* **pwa:** a real-time tutorial on the real engine
* **pwa:** turn-based online matches and the window.Android bridge are gone.
* **pwa:** Firebase Auth, FirebaseUI, Firestore and FCM are gone. Sign-in with Google, Facebook or email and the turn-based online sessions are removed; the multiplayer menu returns with live matches.
* PlayerType.AUGUSTUS_GLOOP, DONALD_TRUMP and VIOLET_BEAUREGARDE are now AI_STRONG, AI_EASY and AI_TUTORIAL.
* requires a runtime with the global Web Crypto API (Node.js >= 20 or a modern browser).
